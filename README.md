## Semaine 2 — Workshop 2 : L'art du prompt

### Ce que j'ai fait
- Répondu au QCM 2 sur la méthodologie du prompting (Zero-shot, Few-shot...)
- Étudié l'anatomie d'un prompt performant : **Rôle → Contexte → Tâche → contraintes → format**
- Expérimenté la différence entre un prompt **Zero-shot** (sans exemples) et un prompt **Few-shot** (avec exemples de démonstration)
- Rempli la fiche **Portfolio Prompt** en suivant la démarche itérative : Prompt V1 → Analyse → Prompt V2 → Comparaison

### Ce que j'ai appris
- **Zero-shot vs Few-shot** : Le Few-shot permet de guider l'IA sur le format et la logique attendus grâce à quelques exemples concrets
- **L'importance des contraintes** : Préciser le public cible, le nombre de mots, le ton et le format améliore considérablement la qualité du résultat
- **Auto-critique & Vérification** : L'auto-critique de l'IA est un outil pour repérer des faiblesses, mais elle ne garantit pas la véracité des faits (la vérification humaine reste obligatoire)

### Difficultés rencontrées
- Ajuster les contraintes pour éviter que la réponse de l'IA ne soit trop générale.
- Bien choisir les exemples Few-shot pour ne pas induire le modèle en erreure
